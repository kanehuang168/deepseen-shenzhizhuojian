# Business decision example: fewer registrations (fictional)

The user reports fewer course registrations and changes to both promotional copy and the registration page. Exposure, clicks, conversion and change dates were not supplied.

Separate the user's report from verified measurements. Consider competing hypotheses: copy or audience changed click behavior; the registration page or submission flow affected conversion; traffic sources, seasonality or another factor changed. These can coexist. Align change dates and the exposure-to-click-to-registration data, check metric definitions and the submission path. A single observation changes confidence but does not prove a cause.

Recommend the cheapest supported read-only next check; make experiments or external changes conditional on actual data and authorization. Do not invent a budget, sample size, deadline or conclusion. If the user only says registration is poor, provide this decision framework and ask for the goal, available data and relevant changes. This is a fictional example, not observed business evidence.
